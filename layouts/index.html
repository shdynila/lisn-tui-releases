LISN-TUI

Neural audio stem separation and multi-track studio workstation in your terminal. Zero cloud dependencies, automated setup, and instant playback.

Bash One-Liner (Universal)
curl -sSL https://raw.githubusercontent.com/shdynila/lisn-tui-releases/main/run.sh | bash
Universal Installer: Automatically detects Linux (x86_64/ARM64), macOS (Apple Silicon/Intel), or Android (Termux with PulseAudio bridge), downloads the latest binary, and launches immediately.

Engine Features

🧠

Neural Stem Separation

Splits stereo audio into isolated Vocals, Drums, Bass, and Synthesizers using 44.1kHz STFT MDX-Net ONNX models with zero cloud dependencies.

🎚️

Multi-Track Studio Mixer

Real-time playback engine with independent channel volumes, instant Solo/Mute toggling, waveform VU visualizers, and scrubber seeking.

📱

Pocket Production

Optimized for ARM NEON vector instructions. Run high-throughput neural inference directly on your smartphone in Termux.

⚡

Zero External Config

Automatically fetches CPU-tailored Microsoft ONNX Runtime shared libraries and neural weights on first launch.
